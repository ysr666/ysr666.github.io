# Shirui Ye — Two independent personal homepage directions

Do not deploy these to production without explicit approval. These designs live on a separate Git branch.

## Open and compare

Run python3 -m http.server 8080 from the repository root, then open:
- http://localhost:8080/prototypes/a.html — A / Signal Studio
- http://localhost:8080/prototypes/b.html — B / Field Notes

Both pages also open as local files with Chrome, including case study links. No build step.

## A / SIGNAL STUDIO

Bold full-bleed electric cobalt, lime accents, coral motion nodes. Original vector/geometry concept based on mechanical linkages, motion and spatial grounding. Pointer/focus subtly adjusts the linkage; reduced-motion preferences keep it predictable. Project panels contain real repository screenshots and source links.

References: Rauno (distinct identity), Emil (controlled interaction), Anthony (personal voice), Paco (structured content), Brittany (career evidence).

## B / FIELD NOTES

Warm editorial backdrop, large scarlet serif typography, lavender, mint and plum chapters. Hero features actual Vision Router and Computer History screenshots as offset work folios, not imaginary interfaces. Project status and limitations remain visible.

References: Anthony (individual voice), Paco (information flow), Brittany (experience), Emil (type/detail), Rauno (inventive composition).
