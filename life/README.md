# Life pages

Public music content is a manually reviewed, deliberately limited presentation of works and theatre experiences, not a personal library export. Adding an item to a private library, playing it, or matching catalogue metadata is not permission to publish it. Never commit a full playlist, private library, listening history, play counts, inferred favourites, or exported source data. Only owner-approved individual public selections may be added. Local import helpers may generate private candidates outside this repository; never copy unreviewed output into the site.

Travel uses the existing approximate route data and approved public places; no private bookings or lodging data. OpenStreetMap attribution and schematic route notices are retained.
