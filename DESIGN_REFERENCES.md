# Five real personal-homepage references
Reviewed live on 2026-10-22 in Chrome at 1440×900, compared directly with the prior site.

| Site | Actual first-view observations | Adaptation |
|---|---|---|
| https://antfu.me/ | Name, concise personal interests, many individual project links in an approximately 650px text column, no dominant photo | Human narrative and honest public work |
| https://paco.me/ | Narrow white editorial page, brief project descriptions and a clear Now section | Small, linkable project rows and current status |
| https://emilkowal.ski/ | Extremely restrained single-column text layout, calm typography, titles open real projects | No fake previews, straightforward work index |
| https://brittanychiang.com/ | Dark split personal résumé; identity and experience prioritized over illustrations | Clear qualification and engineering section |
| https://rauno.me/ | Dramatic intentional editorial/interaction art direction with bright circle and typography | Precision and personal identity only; do not copy artwork |

## Why the prior version failed the user's reference test
The split homepage gave almost half the first viewport to a pinned screenshot and stretched several thousand pixels. It resembled a polished product advertising page, not a personal home. Each selected site is different, but their useful content is primary and their visual language matches the owner's real identity.

## Editorial decision
720px centered text column, real names and repository links, short human introduction, source-backed details one click away. Main landing page intentionally has no images. Original site screenshots remain in published independent project case studies.

Actual reference screenshots were viewed on the connected computer, but not redistributed in the repository.
