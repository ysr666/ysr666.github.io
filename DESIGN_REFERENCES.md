# Reference review — real personal websites

Reviewed on 2026-10-22. These are observations about public sites, not copied designs.

| Website | What worked | Decision for this page |
|---|---|---|
| https://antfu.me/ | Personal open-source identity, source links, real interests | Keep verifiable projects central but use an individual voice |
| https://paco.me/ | Few words, clear Projects and Now paths | Add a concise current-work note without creating another card wall |
| https://brittanychiang.com/ | Role, evidence, résumé and contact easily found | Make navigation lead to Projects / Background / Contact |
| https://emilkowal.ski/ | Actual tools and writing demonstrate craft | Do not invent a blog, studies, metrics or testimonials |
| https://rauno.me/ | Consistent typography and careful interactions | Learn craft without copying the elaborate OS metaphor or excessive motion |

Conclusion: identity, credibility, and useful next actions distinguish mature personal sites. This version reduces duplicated image content, makes ongoing work visible, and preserves explicit technical evidence.
