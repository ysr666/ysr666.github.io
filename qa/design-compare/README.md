# Visual Review of Two Directions

| Factor | A / Signal Studio | B / Field Notes |
|---|---|---|
| Personality | Energetic engineering creator | Expressive editorial creator |
| Palette | Electric cobalt, lime, coral | Scarlet, warm paper, lavender, mint |
| Hero visual | SVG linkage study with pointer/focus movement | Two real project screenshots in offset print-like frames |
| Featured project format | Bright asymmetrical graphic panels | Editorial panels with angled evidence photos |
| Other projects | Colored short index cards | Compact magazine-grid entries |
| Career evidence | Dark awards and skills chapter | Plum awards and skills chapter |
| Mobile | Name and intro then vector graphic | Name and intro then real image collage |
| Interaction | SVG response, hover/focus, bilingual toggle | Controlled hover/focus, bilingual toggle |

Sources of inspiration: Anthony Fu for personal/open-source presence; Paco Coursey for tight information structure; Emil Kowalski for interaction detail; Brittany Chiang for professional evidence; Rauno Freiberg for distinctive art direction.

No reference-site source, code, screenshots, or imagery was copied. All included software screenshots are from the user's own public project repositories.

This is a separate design branch. The official homepage on main is not changed. Review the two alternatives first, then decide whether to refine either or combine a small number of specific elements.
