# Portfolio V6 / Work Records that Serve the CV

**Purpose.** Restore the visual elegance of the official portfolio without giving up creativity. Every interaction must help a visitor understand the work, the individual's contribution, the degree of verification, and the next useful action.

## What has changed from V5

- This is not a return to a static résumé, nor is it a kinetic toy. A distinctive **WORK RECORD** section now sits directly under the hero intro, *next to the sticky real-image preview* on wide screens.
- Choosing **Vision Router**, **Computer History**, or experimental **Agent Wrapped** synchronizes the genuine project preview with a structured résumé reading path: **the problem / the work / verification**.
- Version, release status, risks, image provenance, experimental scope, public source and full case-study links are explicit. The Agent Wrapped preview is typographic artwork, not a fabricated product screenshot.
- The existing eleven-item project and engineering index, search, bilingual support, full case studies, engineering and competition sections, and actual project evidence remain present. A direct intro link now jumps to the work record.
- No fake robot / gesture toy, ungrounded performance figures or imaginary contribution claims.

## Evidence boundaries

Public documentary `FACT_AUDIT.md` is the content ground truth. Vision Router v3.0.5 and the **single** 2.54% pixel-diff screenshot are identified separately; the latter is not claimed as aggregate performance. Keyless fallback can use cloud services. Computer History v1.1.0 defaults to off, has documented platform notes, and any timeline screenshots may contain example data, not real private user activity. Agent Wrapped remains experimental. Awards are based on a self-reported research CV and are not independently authenticated certificates. Engineering coursework/concepts are not presented as integrated robotic hardware evidence.
