Vision Router

开源插件

文字模型不该因为看不见，就失去处理现实界面的能力。

DeepSeek Harness 的文字 Agent 可以调用工具，却不天然具备视觉能力。我做了一个按需启用的视觉路由层：给模型配上图像问答、OCR、局部裁剪、坐标定位、屏幕截图与像素差分等能力。

我更在意它能不能被验证：多后端故障切换、明确的数据流说明，以及可以量化的像素对比循环，而不是只让 Agent 自称“看懂了”。

Computer History

已发布

聊天会结束，但工作不应该每次从零开始。

代码编辑器、文件管理器、浏览器和终端里的活动通常散落在对话以外。Computer History 把有限的应用、资源和时间元数据整理为 Work Episodes，让 Agent 能理解之前在忙什么，并找到适合继续的位置。

隐私约束从设计之初就写进架构：默认关闭采集、用户主动选择应用、本地 SQLite 存储，不采集屏幕截图、按键和文档正文。它已经发布跨平台安装包，但兼容性仍以仓库说明为准。

Agent Wrapped

实验中

一个 Agent 会话里，最有意思的东西未必是 Token 数。

Agent
Wrapped.会话里的名场面

编程 Agent 有时突然找到根因，有时反复宣布“修好了”，又在下一轮推翻自己。我尝试用可追溯的事件与关系图捕捉这些转折，把长会话整理成一份有故事感的回顾。

底层保留事件抽取、关系构建、排序和人工校准步骤；故事与人物画像仍是可选的实验功能，而不是已经完全定型的产品。
