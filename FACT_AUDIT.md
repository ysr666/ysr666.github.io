# Portfolio fact and claim audit
Checked 2026-10-22. Public summary of the audit; no private CV files, personal contacts or certificates are published here.

## Source hierarchy

1. **GitHub repository and release evidence:** public code, README, tags, release notes, source-backed screenshots. These ground functionality, versions, status and limitations. The audit is a documentary review; it does **not** imply independent full-system re-running of every project.
2. **User-authored one-page research CV, September 2026:** education, engineering participation, competition results and CET qualifications. These are self-reported résumé facts, **not independently authenticated award certificates**.
3. **Ongoing project statements supplied by the owner:** projects still being built, scopes and integration status. Unfinished work is labeled.
